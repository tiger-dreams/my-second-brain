# 내 업무로 시작하기

처음에는 서비스 연동이나 영상 도구 설치 없이, 업무 한 건을 기록하는 것부터 시작합니다.

## 1. 내 작업 공간 준비

Git과 로컬 폴더를 읽고 수정할 수 있는 AI 도구가 필요합니다. 기본 사용 환경은 Codex 앱 또는 Claude Desktop의 Code입니다. VS Code나 확장 설치는 필요하지 않습니다. 도구의 계정·요금·설치는 각 도구의 안내를 따릅니다.

```bash
git clone https://github.com/tiger-dreams/my-second-brain.git
cd my-second-brain
```

이 공개 저장소로 실습할 때는 가상 자료를 사용하세요. 실제 업무를 넣으려면 별도의 비공개 저장소를 만들고, 원격 주소가 본인의 비공개 저장소인지 확인합니다. 공개 Fork를 만들면 그 Fork도 공개됩니다.

### Codex 앱

내려받은 `my-second-brain` 폴더를 프로젝트로 열고 로컬에서 대화를 시작합니다. Codex는 `AGENTS.md`를 작업 지침으로 읽고, 이 저장소의 지침에 따라 `CLAUDE.md`의 프로필과 업무 규칙도 읽습니다.

### Claude Desktop의 Code

Code에서 로컬 작업 폴더로 `my-second-brain`을 선택하고 대화를 시작합니다. `CLAUDE.md`는 공통 규칙인 `AGENTS.md`를 가져오도록 구성되어 있습니다. 일반 Chat에 파일을 첨부하는 방식 대신, 저장소 폴더를 읽고 수정할 수 있는 Code 작업을 사용합니다.

## 2. 나에게 맞게 설정

AI에게 이렇게 요청합니다.

```text
AGENTS.md와 CLAUDE.md를 읽고 처음 사용하는 업무 공간으로 설정해줘.
한 번에 하나씩 질문하고, 내 답을 바탕으로 업무 맥락을 정리해줘.
```

팀·역할·반복 업무·사용 도구를 답합니다. 회사 MCP가 없어도 진행할 수 있습니다. 이 단계에서는 프로필을 정리할 뿐 외부 계정이 자동으로 연결되지는 않습니다.

스킬 원본은 `.claude/skills/`에 있고 `.agents/skills/`의 상대 심볼릭 링크로 Codex에도 연결합니다. Codex에서 목록이 갱신되지 않으면 앱을 다시 시작해 확인합니다. 압축 해제나 운영체제 설정으로 링크가 보존되지 않은 환경에서는 다음처럼 원본 경로를 직접 읽도록 요청할 수 있습니다.

```text
.claude/skills/walkthrough-video/SKILL.md를 읽고,
영상 제작에 필요한 입력과 나레이션 초안부터 정리해줘.
```

이 연결은 제작 도구나 음성 모델을 설치하거나 MCP를 연결하지 않습니다.

## 3. 가상 업무 한 건 기록

```text
다음은 실습용 가상 업무야.
오늘 고객 안내 문구 초안을 작성했고 검토는 아직 받지 않았어.
이번 주 로그가 없으면 docs/weekly-logs/weekly_log_YYYY-MM-DD.md를
템플릿으로 이번 주 월요일 날짜의 로그를 만들어줘.
초안 작성 완료와 검토 대기를 구분해서 오늘 기록에 추가해줘.
```

생성한 파일을 열어 날짜·완료 상태·남은 일을 확인합니다. 같은 일을 다시 말했을 때 중복 기록이 생기는지도 확인하고, 자신의 규칙을 추가해보세요.

## 4. 내 업무 흐름으로 바꾸기

- 기록 항목과 상태: `CLAUDE.md`, `AGENTS.md`, 주간 로그 템플릿에서 조정합니다.
- 반복되는 요청: [스킬 만들기](skills-guide/how-to-create-skills.md)를 참고합니다.
- 결과물을 만드는 방법: [PPT 제작](../.claude/skills/pptx/deck-generation.md), [안내 영상 제작](skills-guide/walkthrough-video.md)에서 시작합니다.

스킬을 사용하기 전에 무엇을 입력해야 하는지, 어떤 파일이 만들어지는지 확인합니다. PPT·영상 제작에는 추가 라이브러리나 실행 도구가 필요합니다.

## 5. 필요할 때 연결하고, 공유하기

Slack·메일·캘린더를 읽으려면 자신이 접근할 수 있는 MCP와 권한을 별도로 연결해야 합니다. 사용 가능한 도구가 없다면 직접 제공한 자료나 로컬 기록으로 작업합니다.

다른 사람에게 공유할 때는 개인 업무 기록 대신 일반화한 스킬·가이드·가상 예제를 고릅니다. 무엇을 해결하는지, 어떻게 시작하는지, 그 사람의 환경에 맞게 무엇을 바꿔야 하는지 함께 적어주세요.
