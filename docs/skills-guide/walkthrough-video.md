# 웹 서비스 안내 영상 만들기

릴리즈 문서나 사용 흐름을 입력으로 화면 시연·나레이션·자막이 있는 MP4를 만드는 방법입니다. 반복해서 할 수 있도록 절차를 스킬로 정리했습니다.

## 먼저 알아둘 것

[walkthrough-video 스킬](../../.claude/skills/walkthrough-video/SKILL.md)은 AI가 제작을 진행할 때 읽는 레시피입니다. 이 저장소에는 특정 서비스에 로그인하고 녹화하는 완성된 실행기가 없습니다. 자신의 서비스에 맞게 인증 방법·화면 동작·나레이션을 구성합니다.

기본 도구는 다음과 같습니다. 첫 요청에서는 설치 없이 구성과 스크립트만 검토해도 됩니다.

| 도구 | 역할 |
|---|---|
| 로컬 파일·명령을 다룰 수 있는 AI 도구 | 입력 문서를 읽고 제작 스크립트 작성 |
| Playwright와 지원 브라우저 | 화면 조작과 녹화 |
| piper와 해당 언어의 음성 모델 | 로컬 나레이션 생성 |
| ffmpeg·ffprobe | 오디오·자막·영상 조립과 길이 측정 |

사용할 음성 모델의 언어와 이용 조건, 화면 자료의 공유 범위는 대상에 맞게 확인합니다. 모델에 따라 한국어 지원 여부와 품질이 다릅니다.

## 첫 요청 예시

```text
.claude/skills/walkthrough-video/SKILL.md를 읽어줘.
아래는 실습용 가상 할 일 앱의 변경점이야.
- 완료한 할 일을 접어서 볼 수 있어.
- 날짜로 할 일을 찾을 수 있어.

처음 사용하는 사람을 위한 1분짜리 안내 영상을 만들고 싶어.
먼저 챕터와 한국어 나레이션 초안을 보여줘.
아직 설치하거나 녹화하지 말고, 필요한 화면과 도구도 알려줘.
```

이후 자신의 데모 URL이나 로컬 화면을 제공하고, 초안 확인 → 보이스 샘플 확인 → 챕터 제작 → 합본 검토 순서로 진행합니다. 화면이 없으면 우선 스토리보드까지만 작성합니다.

## 내 서비스에 맞게 바꾸는 부분

- **내용**: 누가 무엇을 이해하거나 완료해야 하는지, 기능 문서와 설명 순서.
- **화면**: 데모 주소, 로그인 상태, 조작할 요소와 화면 전환.
- **음성**: 언어·목소리·약어 발음. 먼저 짧은 샘플을 듣습니다.
- **결과물**: 길이·해상도·자막과 사용처.

실제 데이터 변경이 필요한 장면은 데모 환경이나 mock으로 시연합니다. 자동 녹화에 사용할 인증 상태는 공개하지 않습니다.

## 말과 화면이 어긋나지 않게

나레이션을 문장 단위로 먼저 합성하고 각 길이를 잽니다. 그 길이에 맞춰 화면을 유지하며 녹화하고, 같은 시간표로 오디오와 자막을 만듭니다. 이 순서가 화면을 먼저 길게 녹화한 뒤 음성을 얹는 시행착오를 줄여줍니다.

예를 들어 한 문장이 5초면, 해당 화면 동작을 마친 뒤 짧은 여유를 주고 5초간 유지합니다. 오디오 앞의 무음과 자막 시작 시각에도 같은 여유를 적용합니다.

## 완성 후 확인

- 설명하는 순간에 해당 화면이 보이는지 확인합니다.
- 중요한 버튼·문구와 자막이 읽히는지 대표 프레임을 확인합니다.
- 영상 전체 길이·소리 크기·챕터 연결을 확인합니다.
- MP4와 함께 다음 수정에 쓸 스크립트·챕터 설정·제작 방법을 남깁니다.

이 방법을 다른 사람에게 건넬 때는 완성 영상뿐 아니라 그 사람의 서비스에 맞게 바꿔야 하는 부분도 함께 설명합니다.
