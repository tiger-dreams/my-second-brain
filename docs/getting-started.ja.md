# 自分の業務で始める

[한국어](getting-started.md) · [English](getting-started.en.md) · **日本語**

サービスの接続や動画ツールのインストールをせずに、まず業務を1件記録します。

## 1. 作業場所を用意する

Gitと、ローカルフォルダーを読み書きできるAIツールが必要です。Codexアプリ、またはClaude DesktopのCodeを使います。VS Codeや拡張機能は不要です。アカウント、料金、インストールは各アプリの案内に従ってください。

```bash
git clone https://github.com/tiger-dreams/my-second-brain.git
cd my-second-brain
```

この公開リポジトリでは架空の資料で試してください。実際の業務では別の非公開リポジトリを作り、リモートURLが自分の非公開リポジトリを指していることを確認します。公開リポジトリのForkも公開されます。

### Codexアプリ

ダウンロードしたフォルダーをプロジェクトとして開き、ローカルで会話を始めます。Codexは`AGENTS.md`を読み、その指示に従って`CLAUDE.md`のプロフィールや作業ルールも読みます。

### Claude DesktopのCode

Codeのローカル作業フォルダーとして選択します。`CLAUDE.md`は共通ルールの`AGENTS.md`を読み込みます。通常のチャットにファイルを添付するのではなく、リポジトリを編集できるCodeセッションを使います。

## 2. プロフィールを設定する

```text
AGENTS.mdとCLAUDE.mdを読み、初めて使うワークスペースとして設定してください。
質問は1つずつ行い、回答から私の業務の文脈を整理してください。
回答と業務ログは日本語で書いてください。
```

チーム、役割、定型業務、使用ツール、希望する言語を伝えます。すでに指定した言語は再度質問しません。社内MCPがなくても進められます。この設定だけでは外部アカウントは接続されません。

スキルの原本は`.claude/skills/`にあり、`.agents/skills/`の相対シンボリックリンクでCodexにも接続します。一覧が更新されない場合はアプリを再起動して確認します。リンクが保持されなかった場合は、原本を直接読むように依頼できます。

```text
.claude/skills/walkthrough-video/SKILL.mdを読んでください。
まず動画制作に必要な入力とナレーションの下書きを整理してください。
```

このリンクは制作ツールや音声モデルのインストール、MCP接続を行うものではありません。

## 3. 架空の業務を1件記録する

```text
これは練習用の架空の業務です。
今日、顧客向け案内文の下書きを作成しましたが、まだレビューを受けていません。
今週のログがなければ、docs/weekly-logs/weekly_log_YYYY-MM-DD.mdを
テンプレートにして、今週の月曜日の日付でログを作成してください。
今日の日付の下に、下書きの完了とレビュー待ちを区別して記録してください。
```

生成したファイルを開き、日付、完了状態、残る作業を確認します。同じ内容をもう一度伝えて、重複しないかも確認してください。通常のログは結果、残る行動・返答待ちの相手、根拠リンクの順で書きます。後続作業を追加する前に、既存の完了・承認の根拠を確認します。

## 4. 自分の業務に合わせる

- 共通ルールと記録基準：`AGENTS.md`を編集し、他の文書から参照します。
- プロフィールとツール別案内：`CLAUDE.md`を編集します。書式例は週次ログのテンプレートで管理します。
- 定型作業：[スキル作成ガイド](skills-guide/how-to-create-skills.md)を参照してください。
- 成果物：[PowerPoint作成](../.claude/skills/pptx/deck-generation.md)や[操作説明動画](skills-guide/walkthrough-video.md)から始めます。

スキルを使う前に必要な入力と出力を確認します。プレゼンテーションや動画には追加のライブラリやツールが必要です。リンク先の専門ガイドは現在、韓国語または英語です。

## 5. 必要に応じて接続・共有する

Slack、メール、カレンダーを読むには、MCPと権限を別途設定します。ツールがなければ、提供された資料やローカルの記録で作業します。

共有する際は、個人の業務記録ではなく、一般化したスキル、ガイド、架空の例を選びます。何を解決するのか、始め方、相手の環境で変更が必要な点を添えてください。
