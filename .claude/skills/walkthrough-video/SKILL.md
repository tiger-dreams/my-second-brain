# walkthrough-video

기능 문서와 실제 웹 화면을 바탕으로 사용자가 이해할 수 있는 안내 영상을 만든다. 이 스킬은 범용 제작 절차다. 고정 URL·인증·셀렉터가 포함된 실행기는 제공하지 않으며, 대상 서비스에 맞는 제작 스크립트를 작업 폴더에 작성한다.

## 입력과 진행

1. 설명할 기능·시청자·언어·목표 길이와 접근 가능한 데모 화면을 확인한다. 빠진 정보 중 실제 구성에 필요한 것만 묻는다.
2. 챕터와 짧은 문장 단위의 나레이션 초안을 제시하고 사용자의 확인을 받는다.
3. 설치된 도구를 먼저 확인한다. 기본 조합은 Playwright 녹화, 로컬 piper TTS, ffmpeg 조립이다. 설치·모델 다운로드가 필요하면 도구의 실행 정책을 따른다. 자동으로 설치됐다고 가정하지 않는다.
4. 나레이션 한 문장을 샘플로 합성하고 목소리·발음을 확인받는다. 지원하는 음성 모델과 언어를 확인하며, 영어용 모델을 한국어에 사용하지 않는다.
5. 챕터별로 제작하고 프레임·음량·길이를 검증한다. 합본 MP4와 재현 가능한 소스·필요한 입력을 함께 전달한다. 외부 업로드는 별도 요청에 따른다.

## 화면과 음성의 동기화

나레이션을 문장(beat) 단위로 먼저 합성하고 ffprobe로 길이를 측정한다. 녹화는 각 beat마다 화면 동작 후 여유를 두고 해당 나레이션 길이만큼 화면을 유지한다. 오디오의 선행·간격 무음과 SRT 시간도 같은 타임라인에서 계산한다.

챕터는 제목·경로·문장·자막·화면 동작을 분리한 설정으로 작성한다. `synth → record → assemble` 단계를 각각 재실행할 수 있게 해 수정 시 전체를 다시 만들지 않도록 한다.

## 시연과 검증

- 실제 데이터 저장·삭제·발송이 필요한 장면은 데모 환경 또는 mock 응답으로 화면만 시연한다. 인증은 사용자가 준비한 세션을 재사용하며 녹화 전 페이지 앵커를 확인한다.
- 브라우저 실행·파일 접근은 현재 환경의 권한 정책을 따른다. 화면을 확인하지 못하면 실제 화면 검증을 완료했다고 말하지 않는다.
- 세그먼트의 해상도·fps·오디오 형식을 맞춘 후 concat filter로 합친다. 예: 1280×720, 25fps, 48kHz stereo.
- 최종 길이와 음량을 측정하고 각 챕터의 대표 프레임·자막·내레이션 타이밍을 직접 확인한다. 원본 화면의 비율과 텍스트 가독성을 보존한다.
- 인증 상태 파일·음성 모델·녹화 원본·실제 업무 자료는 로컬 파일로 관리하며 공개 저장소에 포함하지 않는다.
